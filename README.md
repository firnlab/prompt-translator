# Prompt Translator (PT)

A single-file tool-creator: one sentence in, a running, checked digital tool out. Built as a claude.ai artifact from `src/` by `python3 build.py`; every change goes through the gate in `test/`.

- `src/` sources in build order · `dist/` the built file · `test/` all checks (see `RELEASE-CHECKS.md`) · `tools/` repository helpers · `vault/` mirrored open-source tools PT can use (licence-checked) · `PLAN-1.8.md` the next release as decided · `DESIGN-1.8-rev2.md` the design behind it · `FRONTIER-1.8.md` the research base.
- Working rules: `CLAUDE.md`. Release history before 1.8: `RELEASES-ARCHIVE.md`.

This repository is public so its gate, build and triage can run with GitHub's protections. It is not a product with support: there is no support, no roadmap requests, and pull requests are reviewed by the owner only. Questions are welcome as issues and may be closed without answer. Vulnerabilities: see `SECURITY.md`.
